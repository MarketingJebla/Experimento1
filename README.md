# Casa en venta · Villas Xaltipa 1

Landing page estática para promocionar la casa en venta (Modelo Álamo Plus, Cuautitlán, Edo. Méx.).

- `index.html`: página completa (HTML/CSS/JS sin dependencias).
- `img/`: fotos optimizadas en WebP (versión grande y `-sm` para móvil).
- WhatsApp: número y mensajes predefinidos en el bloque `MSGS` al final de `index.html`.

Publicada en Cloudflare Pages (casa-villas-xaltipa.pages.dev) como sitio estático, sin build.
